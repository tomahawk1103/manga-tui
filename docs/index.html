¿Edge muestra «no se descarga habitualmente» o «no seguro» al bajar el .exe?

Manga TUI es código abierto bajo licencia MIT y se compila de forma pública en GitHub Actions. Como todavía no incluye un certificado comercial Authenticode, Microsoft Defender SmartScreen suele advertir en descargas directas de archivos .exe nuevos.

  1. Opción más rápida: usa el instalador de PowerShell de arriba (verifica automáticamente el checksum SHA-256).
  2. Si prefieres descargarlo en Edge (Ctrl + J): pulsa ⋯ junto al archivo → Conservar → Mostrar más → Mantener de todos modos.
  3. Si aparece «Windows protegió su PC» al abrirlo: pulsa Más información → Ejecutar de todas formas.

También puedes comprobar la integridad del archivo comparando su hash con checksum.txt en GitHub Releases ↗.
